# 房屋出租系统 (House Rent System)

## 📖 项目简介
本项目是我在学习 Java 面向对象编程（OOP）阶段，独立完成的一个控制台版房屋出租管理系统。项目采用了分层设计思想，将数据模型、业务逻辑与用户界面分离，是我迈向专业后端开发的重要一步。

## 🚀 功能特性
- **新增房屋**：支持录入房源信息（编号、姓名、电话、地址、租金、状态），底层基于数组实现动态扩容。
- **查找房屋**：通过 ID 精准定位并展示房源详细信息。
- **删除房屋**：采用物理删除（数组元素前移）策略，确保数组空间连续使用。
- **修改信息**：支持修改房屋各项信息，并基于默认值机制实现“直接回车跳过修改”。
- **房屋列表**：格式化输出所有在租/未出租房源。

## 💻 技术栈
- **语言**: Java SE (JDK 8+)
- **开发工具**: IntelliJ IDEA
- **版本控制**: Git & GitHub
- **核心考点**: 面向对象编程（封装、继承、多态）、数组、自定义工具类、异常处理。
